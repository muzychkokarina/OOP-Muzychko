## Відповіді на контрольні запитання

1. **Що таке делегат і для чого він використовується?**  
   Делегат — це тип, що представляє посилання на метод із певною сигнатурою. Він дозволяє передавати методи як параметри в інші методи, зберігати їх у змінних та динамічно викликати під час виконання програми.

2. **У чому полягає різниця між Func та Action?**  
   `Action<T>` використовується для методів, які виконують дію і не повертають значення (`void`). `Func<T, TResult>` використовується для методів, які приймають параметри та обов'язково повертають значення (тип повернуваного значення вказується останнім аргументом дженерика).

3. **Як лямбда-вирази спрощують роботу з делегатами?**  
   Лямбда-вирази дають змогу лаконічно записувати анонімні функції безпосередньо за місцем виклику (через оператор `=>`), уникаючи створення окремих іменованих методів або використання застарілих конструкцій `delegate { }`.

4. **Які переваги дають узагальнені методи при роботі з колекціями?**  
   Узагальнені методи (Generics) дозволяють написати універсальну логіку один раз для будь-якого типу $T$. Це забезпечує строгу типізацію на етапі компіляції (Type Safety), високу продуктивність (без boxing/unboxing) та перевикористання коду.
