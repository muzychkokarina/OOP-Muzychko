## Мета роботи
Ознайомитися з принципом наслідування в об'єктно-орієнтованому програмуванні, навчитися створювати ієрархії класів, використовувати ключові слова `base`, `virtual`, `override` та `new`.

---

## Теоретичні відомості
- **Наслідування:** механізм ООП, що дозволяє створити новий клас на основі існуючого.
- **`base`:** ключ для доступу до членів базового класу (зокрема конструктора).
- **`virtual` та `override`:** використовуються для реалізації поліморфізму (динамічне зв'язування).
- **`new`:** виконує приховування члена базового класу (статичне зв'язування).

## Відповіді на контрольні запитання
1. **Що таке наслідування?** Це принцип ООП, який дозволяє одному класу успадковувати властивості та методи іншого.
2. **Для чого використовується `base`?** Для виклику конструкторів або методів базового класу з похідного.
3. **Чим відрізняються `override` та `new`?** `override` реалізує поліморфізм (викликається метод об'єкта), а `new` приховує метод базового класу (визначення залежить від типу посилання).
