## Відповіді на контрольні запитання
1. **Що таке поліморфізм і як він реалізується в C# за допомогою virtual та override?**  
   Поліморфізм — це здатність об'єктів різних класів реагувати на однаковий виклик методу по-різному. У C# метод базового класу позначається як `virtual`, а в похідних класах перевизначається за допомогою `override`.

2. **Поясніть поняття динамічного зв’язування. Чим воно відрізняється від статичного?**  
   Динамічне зв’язування (Late Binding) означає, що вибір конкретного методу для виконання відбувається під час работы програми (runtime) залежно від реального типу об'єкта. Статичне зв’язування відбувається на етапі компіляції.

3. **Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код.**  
   Якщо потрібно додати новий тип сенсора (наприклад, `HumiditySensor`), ми просто створюємо новий клас і перевизначаємо `GetReading()`. Основний цикл обробки списку `List<Sensor>` змінювати не потрібно.

4. **Які переваги дає використання колекцій базових типів для роботи з поліморфними об’єктами?**  
   Це дозволяє зберігати об'єкти різних похідних класів в одній колекції та обробляти їх уніфіковано в єдиному циклі.
