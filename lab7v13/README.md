## Відповіді на контрольні запитання

1. **Яка роль where-обмежень у Generics? Наведіть приклади їх використання.**  
   `where`-обмеження гарантують, що тип-параметр $T$ володіє певними властивостями або реалізує конкретні інтерфейси. Наприклад, `where T : IEntity` гарантує, що у будь-якого об'єкта типу $T$ буде властивість `Id`.

2. **Навіщо потрібен шаблон IRepository? Які переваги він дає?**  
   Шаблон `IRepository` абстрагує логіку доступу до даних від бізнес-логіки. Це дає змогу легко змінювати джерело даних (наприклад, замінити `InMemory` на базу даних SQL) без зміни основного коду програми.

3. **Поясніть, чому юніт-тести є важливими при розробці узагальнених компонентів.**  
   Узагальнені компоненти призначені для роботи з різними типами даних. Юніт-тести дозволяють переконатися, що універсальна логіка (CRUD, пошук, видалення) працює безпомилково у всіх граничних випадках.

4. **Які проблеми вирішують Generics порівняно з використанням object?**  
   Generics забезпечують строгу типізацію на етапі компіляції (Type Safety) та уникають втрати продуктивності через упакування/розпакування (boxing/unboxing) значущих типів.
