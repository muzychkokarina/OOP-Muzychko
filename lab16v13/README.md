## Аналіз продуктивності та висновки
- **Операції Join та GroupJoin** виявилися більш ресурсомісткими порівняно з звичайною фільтрацією `Where`, оскільки вони вимагають співставлення ключів двох різних колекцій.
- **Синтаксис методів (Method syntax)** та **синтаксис запитів (Query syntax)** під час компіляції розгортаються у тотожний код на мові C#, тому відмінності у часі їх виконання мінімальні та знаходяться у межах похибки вимірювань.
- **Агрегатні операції (`Max`, `Count`)** викликають негайне виконання (Immediate Execution) LINQ-запиту, тоді як збереження запиту без операцій матеріалізації (`ToList()`, `ToArray()`) використовує відкладене виконання (Deferred Execution).

## Відповіді на контрольні запитання

1. **Поясніть різницю між синтаксисом запитів та синтаксисом методів у LINQ. Коли який краще використовувати?**  
   Синтаксис запитів (Query syntax) зовні схожий на SQL (`from ... in ... where ... select`), що робить його зручним для складних операцій з `join` та `group`. Синтаксис методів (Method syntax) базується на виклику розширюючих методів і лямбда-виразах (`.Where()`, `.Select()`); він є більш гнучким і дозволяє використовувати операції, які не підтримуються безпосередньо у Query syntax (наприклад, `Take`, `Skip`, `First`).

2. **Для чого використовуються операції Join та GroupJoin? У чому їхня відмінність?**  
   Операція `Join` з'єднує дві колекції на основі ключа і повертає плоский набір пар ("один до одного"). `GroupJoin` об'єднує елементи так, що кожному елементу з першої колекції відповідає ціла група збігів з другої колекції ("один до багатьох"), що зручно для ієрархічних даних.

3. **Наведіть приклади агрегуючих операцій LINQ та поясніть їхнє призначення.**  
   - `Count()` — підраховує кількість елементів у колекції або тих, що відповідають умові.
   - `Sum()` — обчислює суму числових значень.
   - `Average()` — обчислює середнє арифметичне значення.
   - `Min()` / `Max()` — знаходить найменше або найбільше значення.
   - `Aggregate()` — виконує довільну акумулятивну функцію над елементами.

4. **Як можна виміряти продуктивність LINQ-запитів? Які фактори впливають на неї?**  
   Продуктивність можна виміряти за допомогою класу `System.Diagnostics.Stopwatch`, фіксуючи час або тики до і після виконання запиту. На продуктивність впливають: розмір колекцій, складність умови фільтрації, тип операції (сканування всієї колекції при агрегації), час матеріалізації (`ToList()`), а також ефект відкладеного виконання (Deferred Execution).
