## Мета роботи
Ознайомитися з середовищем розробки, навчитися створювати класи та працювати з базовими елементами ООП у C#. Налаштувати середовище розробки, ознайомитися з принципами інкапсуляції та роботою з версіями через Git.

---

## Теоретичні відомості
- **Клас** — це шаблон для створення об’єктів, що описує дані (поля) та поведінку (методи).
- **Конструктор** — спеціальний метод для ініціалізації початкового стану об’єкта.
- **Інкапсуляція** — приховування внутрішніх деталей реалізації за допомогою приватних полів та контрольованого доступу через публічні властивості (`get`, `set`).

---

## Хід роботи
1. Встановлено середовище Visual Studio Code та розширення C# Dev Kit, .NET Install Tool.
2. За допомогою CLI .NET створено консольний проєкт `lab1v13` у директорії `OOP-Muzychko`.
3. У файлі `Program.cs` реалізовано клас відповідно до Варіанта 13 (`Library`):
   - Приватні поля (`name`, `address`, `booksCount`);
   - Публічні властивості для доступу та валідації (`Name`, `Address`, `BooksCount`);
   - Конструктор класу та метод `AddBook()`.
4. У методі `Main` створено об’єкти класу, викликано їхні методи та виведено результати роботи в консоль.
5. Налаштовано файл `.gitignore` відповідно до стандартів .NET та VS Code.
6. Ініціалізовано локальний Git-репозиторій та вивантажено проєкт на GitHub.
