## Мета роботи
Поглибити розуміння життєвого циклу об’єкта в C#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс `IDisposable` та повноцінний паттерн Dispose.

---

## Теоретичні відомості
- **Керовані ресурси:** пам’ять, що виділяється під об’єкти .NET та автоматично очищується збирачем сміття (GC).
- **Некеровані ресурси:** системні дескриптори, файли, з'єднання з БД, потоки, що потребують явного звільнення.
- **Інтерфейс `IDisposable`:** надає стандартний метод `Dispose()` для звільнення ресурсів.
- **Оператор `using`:** гарантує автоматичний виклик `Dispose()` при виході з блоку коду.
- **`GC.SuppressFinalize(this)`:** повідомить збирачу сміття, що об'єкт вже звільнив ресурси вручну, тому деструктор викликати не потрібно.

## Хід роботи
1. Створено новий проєкт `lab3v13` у директорії `OOP-Muzychko`.
2. Реалізовано клас `CustomThreadPool` згідно з Варіантом 13:
   - Поля `_poolSize` та `_isActive`.
   - Метод `ExecuteTask(string taskName)`.
   - Повний паттерн Dispose (`Dispose()`, захищений `Dispose(bool)`, деструктор `~CustomThreadPool()`).
3. Продемонстровано 3 сценарії використання у `Main`:
   - Автоматичне звільнення через `using`.
   - Явний виклик `Dispose()`.
   - Автоматичний виклик деструктора через збирач сміття `GC.Collect()`.
