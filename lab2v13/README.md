## Мета роботи
Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів (ланцюговий виклик `: this()`) та зрозуміти основи життєвого циклу об’єкта й роботу збирача сміття (Garbage Collector) у C#.

---

## Теоретичні відомості
- **Перевантаження конструкторів:** можливість створення декількох конструкторів з різним набором параметрів.
- **Ланцюговий виклик (`: this()`):** перенаправлення виклику з одного конструктора до іншого для уникнення дублювання коду.
- **Життєвий цикл об'єкта:** Створення (`new`) -> Використання -> Знищення (`Garbage Collector`).
- **Деструктор (`~ClassName()`):** спеціальний метод, який автоматично викликається збирачем сміття перед вилученням об'єкта з пам'яті.
