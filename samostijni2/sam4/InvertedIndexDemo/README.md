# Самостійна робота №16: Колекції в практиці ООП: інвертований індекс і вимірювання продуктивності

## Опис проєкту
Консольний застосунок **`InvertedIndexDemo`** реалізує структуру даних **Inverted Index (інвертований індекс)** на мові C# для швидкого повнотекстового пошуку по колекції документів та порівнює її ефективність із класичним лінійним пошуком.

### Основний функціонал:
- **Пошук за одним словом** (`SearchSingleWord`) — миттєве отримання списку документів за ключем у `Dictionary<string, HashSet<int>>`.
- **Пошук за всіма словами — логічне AND** (`SearchMultipleWords`) — знаходження спільних документів через перетин множин `HashSet<int>.IntersectWith`.
- **Пошук за будь-яким словом — логічне OR** (`SearchAnyWord`) — об'єднання результатів через `HashSet<int>.UnionWith`.
- **Нормалізація тексту** (`TextProcessor`) — приведення до нижнього регістру, очищення від пунктуації за допомогою регулярних виразів та фільтрація стоп-слів.
- **Вимірювання продуктивності** (`PerformanceTest`) — тестування швидкодії лінійного пошуку та інвертованого індексу за допомогою `Stopwatch` на вибірках із 10, 100, 1 000 та 10 000 документів.
